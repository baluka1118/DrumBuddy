DrumBuddy User Guide

Install, configure, record, play MIDI, and route sheets to GarageBand and other apps.

What is DrumBuddy?

DrumBuddy is a cross-platform desktop app for drummers. It lets you:

  • Record beats from an electronic drum kit (or keyboard) onto a digital sheet
  • Create sheets manually in a step-based editor
  • Store sheets in a local library
  • Compare two sheets to see timing and note differences
  • Export to JSON, MIDI, MusicXML, or PDF
  • Play sheets to an external MIDI output (e.g. GarageBand via IAC Driver)
  • Sync sheets to the cloud when signed in
No built-in drum sounds During recording you hear a metronome only. To hear drum kit audio, route MIDI output to a DAW or drum module.

Current rhythm limits: 4/4 time only; smallest division is a 16th note.

Installation

Windows

  1. Download DrumBuddy-Setup-x.y.z.exe from GitHub Releases.
  2. Run the installer.
  3. Launch from the Start Menu.
SmartScreen warning Choose More info → Run anyway if Windows blocks an unsigned build.

Linux

chmod +x DrumBuddy-linux-x64.AppImage
./DrumBuddy-linux-x64.AppImage

macOS (pre-built release)

Apple Silicon

  1. Download DrumBuddy-osx-arm64.dmg from GitHub Releases.
  2. Drag DrumBuddy.app to Applications.
  3. Run in Terminal:
cd /Applications
sudo xattr -cr DrumBuddy.app
sudo xattr -rd com.apple.quarantine DrumBuddy.app
sudo codesign --force --deep --sign - DrumBuddy.app

Intel Macs: use DrumBuddy-osx-x64.dmg with the same steps.

First Launch: Account vs Guest Mode

Sign in with an account

  • Enables cloud sync for marked sheets
  • Requires network access to the DrumBuddy API

Continue as a guest (offline mode)

  • Click Continue as a guest (offline mode)
  • All sheets stored locally; no cloud sync UI
  • Full recording, editing, export, and MIDI playback still work

MIDI Input: Electronic Drums & Keyboard Mode

Electronic drum kit

  1. Connect the module via USB.
  2. Power on the module.
  3. Choose a MIDI input device when prompted (if multiple exist).

If disconnected, use Configuration → Settings → Choose again.

Keyboard mode

  1. Configuration → Settings
  2. Toggle Keyboard Mode on
  3. Use mapped keys in Record and edit dialogs

Remapping drums

  1. Configuration → Drum Mapping
  2. Click Remap next to a drum
  3. Hit the pad or key to assign

Supported: Kick, Snare, Tom1, Tom2, Floor Tom, Hi-Hat (closed/open/pedal), Ride, Crash1, Crash2.

Recording Sheets

  1. Open Record.
  2. Set BPM.
  3. Optionally load a reference sheet overlay.
  4. Click Record — countdown, then metronome and capture.
  5. Use Pause/Resume as needed; Stop when done.
  6. Save with name and description.

Requires a MIDI device or keyboard mode.

Playing Sheets via MIDI Output

  • Notes on MIDI channel 10 (GM drums)
  • Same data as MIDI file export
  • Play from Manual Editor or Library

On macOS, choose IAC Driver Bus 1 to route into GarageBand.

Hearing Sheets in GarageBand (macOS)

1. Enable IAC Driver

  1. Open Audio MIDI Setup
  2. Window → Show MIDI Studio
  3. Double-click IAC Driver
  4. Check Device is online
Not in GarageBand settings IAC is configured in Audio MIDI Setup, not GarageBand preferences.

2. Configure GarageBand

  1. Add a Software Instrument track (green) with a drum kit
  2. Track → Configure Track Header → Record Enable
  3. Arm the drum track (Record Enable button)

External MIDI goes to the armed Software Instrument track — there is no separate “MIDI from IAC” per-track setting.

3. Play from DrumBuddy

  1. Library or Manual Editor → Play MIDI
  2. Select IAC Driver Bus 1 if prompted
  3. Hear drums on the armed GarageBand track

Comparing Sheets

  1. Library → select sheet → Compare
  2. Pick a second sheet
  3. Review side-by-side with highlights

Building from Source

git clone https://github.com/sz-balage/DrumBuddy.git
cd DrumBuddy

# Homebrew dotnet on Apple Silicon:
export DOTNET_ROOT="/opt/homebrew/opt/dotnet/libexec"

dotnet run --project DrumBuddy.Desktop/DrumBuddy.Desktop.csproj -c Debug -r osx-arm64

Runtimes: osx-x64, win-x64, linux-x64. Docker stack optional for API/sync.

Troubleshooting

No MIDI input

  • Check USB and module power
  • Configuration → Choose again
  • Or enable Keyboard Mode

No MIDI output

  • Enable IAC Driver (macOS)
  • Restart DrumBuddy after enabling devices

GarageBand silent

  • IAC online; Software Instrument + drum kit; track armed
  • Correct IAC bus selected in DrumBuddy

macOS won’t open app

Run quarantine commands under Installation above.

Known Limitations

  • 4/4 only; 16th notes max
  • No built-in drum audio (metronome when recording)
  • GM drums on channel 10 for MIDI output
  • macOS builds need manual quarantine removal
