# DrumBuddy Documentation

User-facing documentation for the DrumBuddy desktop application.

| Format | File | Best for |
|--------|------|----------|
| **Markdown** | [USER_GUIDE.md](USER_GUIDE.md) | Obsidian, editing, GitHub (use HTML for clickable TOC on GitHub) |
| **HTML** | [USER_GUIDE.html](USER_GUIDE.html) | Browser reading, offline sharing, printing |

Open the HTML guide locally:

```bash
open docs/USER_GUIDE.html          # macOS
xdg-open docs/USER_GUIDE.html      # Linux
start docs/USER_GUIDE.html         # Windows
```

The online documentation at [docs.drumbuddy.hu](https://docs.drumbuddy.hu/) is maintained separately; this folder is the in-repo copy and includes **MIDI playback** and **GarageBand / IAC setup** instructions for local development builds.
